Frequently Asked Questions

Everything you need to know about using PixelTools. Can't find an answer? Contact us.

Are my images really processed on my device?

✓

Yes. Every PixelTools tool runs 100% in your browser using the Canvas API and FileReader. Your images are never sent to a server — they exist only in your device's memory while you work.

Do I need to create an account to use these tools?

✓

No. There is no signup at all. Just open a tool page and you can upload, process, and download images immediately.

Will compression reduce the quality of my photos?

✓

It can, but only if you want it to. The compressor includes a quality slider so you can see the file-size reduction live before choosing a setting. For most photos, a modest reduction like 80–85% quality is invisible to the eye.

What image formats are supported?

✓

We support JPG, PNG, and WebP. PNG files support transparency, and WebP conversions follow the standard browser support (Chrome, Edge, Safari 14+, Firefox 65+).

Can I use these tools on my phone or tablet?

✓

Absolutely. All tools are fully responsive and tested on mobile. The gesture controls on the cropper work with touch, and the upload zone accepts files from the photo library.
